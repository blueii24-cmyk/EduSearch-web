# EduSearch

EduSearch is a React/Vite frontend for discovering colleges, jobs, internships, and career paths.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Deployment

This project can be deployed to Vercel with the framework preset set to **Vite**. Use `npm run build` as the build command and `dist` as the output directory.
